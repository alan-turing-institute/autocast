# CLI walkthrough

Follow a complete experiment from [generating an AutoSim dataset](simulate-data.md)
through training, cached latents and [evaluation](eval.md), using AutoCast's CLI
and Hydra configuration. This walkthrough is self-contained; no notebooks are
required.

For a short Python introduction, start with the
[quickstart](../tutorials/quickstart.ipynb). The
[focused notebooks](../tutorials/index.md) explore individual model and evaluation
choices with small datasets and plots.

After evaluating your experiments, use
[evaluation and results](../tutorials/evaluation_and_results.ipynb) to inspect
metrics and compare saved runs.
